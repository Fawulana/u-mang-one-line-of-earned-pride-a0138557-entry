# One Line of Earned Pride

make.fun entry for `u-mang-one-line-of-earned-pride-a0138557`.

`main.py` (Python 3.13, stdlib-only) writes a single fixed line of text —
a quiet, earned moment of pride — to `/output/entry.txt`. Deterministic:
the line is a string constant, so every run produces byte-identical output.
No network, no randomness, no clock, no environment reads.

## The line

> After three years of weekends in the garage, Luis turned the key, and the truck he'd rebuilt from scrap finally caught and idled — and he just sat there, hands still greasy, listening to it run.

194 characters, within the 1–240 character gate.
